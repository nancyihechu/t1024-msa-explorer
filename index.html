1. Interactive MSA

Choose a color scheme, jump to a T1024 residue, or change the visible window. Green-tinted columns are fully conserved across all 10 sequences.

2. Conservation and gap-frequency plots

Conservation is a normalized Shannon-entropy score (0–1) multiplied by column occupancy, so highly variable or gappy columns score lower. The gap plot shows the fraction of sequences containing a gap at each alignment column.

3. Sequence logo

The logo is shown for the same visible alignment window as the MSA. Letter height reflects amino-acid frequency weighted by information content; taller stacks indicate stronger conservation.

4. Consensus sequence

Consensus is the most frequent non-gap amino acid at each alignment column. Use the button to copy the aligned consensus sequence.







  
5. Highly conserved regions

  
Adjust the threshold to find contiguous T1024 regions with high conservation. Regions require no T1024 gap and are reported using T1024 residue numbers.
